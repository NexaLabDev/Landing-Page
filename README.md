# Nexa Lab — Site institucional

Site público e estático da Nexa Lab para apresentação de soluções e informações institucionais.

## Estrutura
- `index.html`: página institucional (sem autenticação).
- `style.css`: identidade visual responsiva.
- `privacidade.html`: política de privacidade.
- `termos.html`: termos de uso.
- `favicon.svg`: ícone abstrato de site.
- `robots.txt`: acesso permitido a indexadores.

## Implantação
Hospedar como site estático na Vercel, framework `Other`, sem build e sem variáveis de ambiente.
A Nexa Workspace permanece em um projeto separado com seu próprio login.
